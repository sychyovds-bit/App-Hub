# AppHub — Портал приложений

Прогрессивное веб-приложение (PWA): коллекция мини-приложений в одном портале. Чистый JS без фреймворков и сборки.

## Запуск

Приложение использует ES-модули, поэтому нужен любой статический сервер (не `file://`):

```bash
# Node.js (npx без установки)
npx serve .

# или Python
python -m http.server 8080
```

Откройте http://localhost:3000 (или :8080 для Python).

## Структура

```
apphub/
├── index.html          # Оболочка: sidebar, модалка, секции
├── manifest.json       # PWA-манифест (иконки, тема)
├── sw.js               # Service Worker (офлайн-кэширование)
├── icons/              # PWA-иконки 192×192 и 512×512
├── core/               # Ядро портала
│   ├── app.js          # Регистрация приложений и сборка UI
│   ├── router.js       # Hash-навигация, горячие клавиши
│   ├── registry.js     # Реестр приложений, lazy import(), preload
│   ├── storage.js      # localStorage: экспорт/импорт/квота
│   ├── modal.js        # Диалоги с фокус-ловушкой
│   ├── toast.js        # Уведомления (aria-live)
│   ├── theme.js        # Светлая/тёмная тема
│   ├── preview.js      # Живой предпросмотр карточки при hover
│   ├── utils.js        # debounce(), throttle()
│   ├── idb.js          # IndexedDB для больших заметок
│   ├── cloud.js        # Синхронизация через Supabase (опционально)
│   ├── config.js       # Конфиг Supabase (URL + anon key)
│   ├── icons.js        # SVG-иконки
│   └── favicon.js      # Динамический favicon с прогрессом
├── apps/               # 31 приложение, каждое = ES-модуль с init()
├── lib/                # Внешние библиотеки (qrcode, supabase)
├── styles/             # base.css (токены темы) + components.css
└── supabase/           # schema.sql для таблицы kv_data + RLS
```

## Как добавить приложение

1. **Создайте файл** `apps/myapp.js`:

```js
import { storage } from '../core/storage.js';
import { toast } from '../core/toast.js';

export function init(container) {
  container.innerHTML = `
    <h1>Заголовок</h1>
    <p class="subtitle">Подзаголовок</p>
    <div class="widget">...</div>
  `;
  // ваша логика...
}
```

2. **Зарегистрируйте** в `core/app.js`:

```js
registry.add({
  id: 'myapp',
  title: 'Название',
  description: 'Описание для карточки',
  icon: 'gear',               // ключ из core/icons.js
  category: 'tools',          // productivity|tools|dev|creative|text|security|games
  load: () => import('../apps/myapp.js')
});
```

3. **Добавьте иконку** в `core/icons.js` (ключ → строка SVG), если нет подходящей.

4. **Service Worker**: имена путей вида `/apps/*.js` кэшируются автоматически. После изменения любых файлов ядра поднимите версию кэша: `sw.js` → `CACHE_NAME = 'apphub-v10'`…

Данные храните через `storage.get/set('ключ', значение)` — тогда экспорт/импорт и облако подхватят их автоматически.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+K | Палитра команд (поиск приложений и быстрых действий) |
| Alt+0 | Главная |
| Alt+1…9 | Переключение категорий |
| Enter / Space | Активация карточки (фокус с клавиатуры) |
| Tab | Навигация фокуса |

## Фишки

- **Undo** — удаление задачи/карточки отменяется кнопкой в уведомлении (5 сек)
- **Звезда** — закрепление в разделе «Избранное» (порядок закрепления)
- **Карандаш** у категории — своё название (кнопка «Сбросить» вернёт стандартное)
- **Темы** — 4 цветовых семейства × светлая/тёмная (палитра в сайдбаре)
- **Свайп от левого края** на мобильных — назад; кнопка «←» в хлебных крошках
- **Уведомления** — системные по окончании таймера (запрос разрешения при первом старте)
- **Подсказки** — кнопка «?» в сайдбаре, показываются при первом запуске

## Офлайн и данные

- Все данные — в localStorage браузера (Импорт/Экспорт в сайдбаре).
- Service Worker кэширует оболочку и модули; HTML — network-first, статика — cache-first.
- Супабейз-облако по умолчанию отключено: заполните `SUPABASE_URL` и `SUPABASE_ANON_KEY` в `core/config.js` и выполните `supabase/schema.sql` в своей Supabase-базе.
